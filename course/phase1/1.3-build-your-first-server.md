# Lesson 1.3 — Build Your First Server

**3 hours · Beginner · Prereq: 1.1, 1.2**

## Objectives
Create an MCP server with the SDK; define tools with typed parameters; run it; connect the Inspector and call your tools.

## A minimal server has four parts
1. **Create the server** — `FastMCP("name")` (the name is the `serverInfo` from 2.2)
2. **Define tools** — decorate a function with `@server.tool()`; type hints become the input schema, docstring becomes the description
3. **The function body** — does the work, returns a JSON-serializable value
4. **Run it** — `server.run()` starts the event loop, listening over STDIO by default

## The code (verified working on SDK v1.29)

```python
from mcp.server.fastmcp import FastMCP

server = FastMCP("demo")

@server.tool()
def add(a: float, b: float) -> float:
    """Add two numbers and return the sum."""
    return a + b

@server.tool()
def greet(name: str) -> str:
    """Return a friendly greeting for the given name."""
    return f"Hello, {name}!"

if __name__ == "__main__":
    server.run()
```

Full file: [`../../code/phase1/demo_server.py`](../../code/phase1/demo_server.py).

Run it:
```bash
python demo_server.py                                         # STDIO, appears to "hang" — correct
npx @modelcontextprotocol/inspector python demo_server.py     # explore in the Inspector
```

The auto-generated schema (verified): `add` → `a`,`b` required numbers; `greet` → `name` required string; docstrings become descriptions.

## Why This Design Exists
The decorator keeps the tool's *definition* and *implementation* together — the function IS the tool. The schema is generated from type hints (no hand-written JSON Schema to drift out of sync). STDIO is the default because it's simplest for local dev.

## Common bugs to know
- **Missing `@server.tool()`** → tool never appears (not registered)
- **No type hints** → weak/missing schema
- **Non-serializable return** (e.g. a `set`) → serialization error
- **`print()` to stdout on STDIO** → corrupts the protocol wire (log to stderr instead)
- **Forgot `server.run()`** → nothing listens

## Key Takeaways
- A minimal server: create `FastMCP`, decorate functions as tools, `run()`.
- Type hints → input schema; docstring → description; the SDK generates both.
- The SDK handles all the Phase 2 protocol for you.
- Return JSON-serializable values; never `print()` to stdout on STDIO.
